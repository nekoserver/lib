preprintの確認済み機能（実Chromiumタブのmarkdown投影、1行のaction追記による操作、再読み込みで最新refを使う、console・画像等の記録）を前提に提案します。

有用な用途3件
1. 公開画面の表示・接続状態の確認。Workerや認証状態を目視で確かめられます。
2. 移植前後のUI差分とconsole採取。同一画面の表示差分とエラーを記録できます。
3. 同一Jobの再訪と結果表示の確認。Jobと実回答の区別を目視で検証できます。

最初の一歩：公開の仕様書・共有ページを1画面だけ対象に、初回はno-profileの独立sessionで開き、表示とconsoleを記録します。完了条件はmarkdown投影とconsole記録が残ること。成果物は投影結果とconsoleログです。

Playwright等との使い分け：自動操作や検証は既存手段、preprintは人の目視確認と記録の補助です。制約として、preprintはHTTP API・SDKの結果検証やWASM起動の代用にはならず、既存のログインプロファイルは使いません。

追加の有望案：画面ごとの確認記録を、未解決事項の整理とPRへの検証根拠保存に使います。
