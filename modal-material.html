基本ダイアログ

delete_forever
データを完全に削除しますか？
削除されたデータは復元できません。関連するすべてのファイルも合わせて削除されます。
phone_android
デバイスをリセットしますか？
工場出荷時の設定に戻ります。すべてのデータ、アカウント、アプリが削除されます。

Basic Dialog 
<!-- Material Design 3 Dialog -->
<div class="md-scrim" id="myDialog">
  <div class="md-dialog">
    <div class="md-dialog-title">タイトル</div>
    <div class="md-dialog-body">内容</div>
    <div class="md-dialog-actions">
      <button class="md-btn md-btn-text">キャンセル</button>
      <button class="md-btn md-btn-text">OK</button>
    </div>
  </div>
</div>

/* CSS: M3 Dialog */
.md-scrim {
  position: fixed; inset: 0;
  background: rgba(0,0,0,.32);
  display: flex; align-items: center; justify-content: center;
  opacity: 0; visibility: hidden;
  transition: opacity .2s;
}
.md-scrim.active { opacity: 1; visibility: visible; }

.md-dialog {
  background: #fffbfe;
  border-radius: 28px;      /* M3 の角丸 */
  padding: 24px;
  max-width: 560px;
  box-shadow: 0 8px 24px rgba(0,0,0,.15);
  transform: scale(0.9);
  transition: transform .25s cubic-bezier(.05,.7,.1,1);
}
.md-scrim.active .md-dialog { transform: scale(1); }
