transition-property
変化させる CSS プロパティを指定します。all を使うと全てのプロパティが対象になります。
transition-duration
トランジションの所要時間を設定します。0.3s〜0.5s が自然な感覚の目安です。
transition-timing-function
ease, linear, cubic-bezier() などで加減速カーブを調整できます。
transition-delay
トランジション開始までの待ち時間。スタガーアニメーションに便利です。
