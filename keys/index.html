SSH KEY TOOLS

PKCS#8 キーペア

別のクライアントで使う秘密鍵を、このブラウザで作成します。

1. キーを生成

RSA の秘密鍵は未暗号化の PKCS#8（PEM）です。秘密鍵はサーバーへ送信せず、このページを閉じると消えます。ダウンロードして保存してください。

生成ボタンを押してください。

2. 保存・コピー

秘密鍵ファイルを SSH で使う場合は chmod 600 private-key.pem を実行してください。

3. このVMに公開鍵を登録

このVMの root ユーザーの authorized_keys に追加します。既存の鍵は保持します。登録には既存APIと共通の HMAC キーが必要です。

秘密鍵は端末へ保存し、使用するクライアントに取り込んでください。
